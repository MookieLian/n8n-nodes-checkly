# Changelog

## 0.1.0

- Initial release.
- **Checkly** node (declarative): Check, Check Group, Check Result, Check Status, Alert Channel, Dashboard, Snippet, Environment Variable, Maintenance Window, Location and Runtime resources.
- **Checkly Trigger** node: webhook trigger that auto-registers a Checkly webhook alert channel on activation and removes it on deactivation, with optional `x-checkly-signature` verification.
